# Multiple Sequence Alignment

This project implements multiple approaches to the Multiple Sequence Alignment (MSA) problem for protein sequences.

## Implementations

- Genetic Algorithm for MSA
- Brute-force approach for small test cases
- Comparison with ClustalW algorithm

## Fitness Function

Uses Sum-of-Pairs (SP) score with BLOSUM62 substitution matrix and affine gap penalties.

## Evaluation

The genetic algorithm is evaluated against ClustalW on the BAliBASE RV11 benchmark dataset.
